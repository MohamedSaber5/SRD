Factory Method: Defines an interface for creating an object, but lets subclasses alter the type of
object that will be created.
code template :
// Define the Transport interface
interface Transport { 
    void deliver(); 
}

// Implement Truck and Ship classes
class Truck implements Transport {
    public void deliver() {
        System.out.println("Truck delivering goods by land.");
    }
}

class Ship implements Transport {
    public void deliver() {
        System.out.println("Ship delivering goods by sea.");
    }
}

// Abstract Logistics class with a factory method that takes a control parameter
abstract class Logistics {
    // Factory method: it takes a 'mode' parameter to decide which Transport to create.
    protected abstract Transport createTransport(String mode);
    
    public void deliverCargo(String mode) {
        Transport t = createTransport(mode);
        t.deliver();
    }
}

// Instead of having separate subclasses for each product type, we use one subclass.
class UniversalLogistics extends Logistics {
    // Here we use the control parameter 'mode' to choose the correct Transport.
    protected Transport createTransport(String mode) {
        if (mode.equals("land")) {
            return new Truck();
        } else if (mode.equals("sea")) {
            return new Ship();
        } else {
            throw new IllegalArgumentException("Unknown mode: " + mode);
        }
    }
}

// Client code
public class FactoryMethodDemo {
    public static void main(String[] args) {
        Logistics logistics = new UniversalLogistics();
        logistics.deliverCargo("sea");  // Output: Ship delivering goods by sea
        logistics.deliverCargo("land"); // Output: Truck delivering goods by land
    }
}

adpter:The adapter is a structural design pattern that allows objects with incompatible

// Common interface for pegs (Target Interface)
interface Peg { 
    double getRadius();
}

// RoundPeg implements Peg
class RoundPeg implements Peg {
    private double radius;
    
    public RoundPeg(double radius) {
        this.radius = radius;
    }
    
    @Override
    public double getRadius() {
        return radius;
    }
}

// SquarePeg (Incompatible Class - Adaptee)
class SquarePeg {
    private double width;
    
    public SquarePeg(double width) {
        this.width = width;
    }
    
    public double getWidth() {
        return width;
    }
}

// RoundHole expects objects that implement Peg interface
class RoundHole {
    private double radius;
    
    public RoundHole(double radius) {
        this.radius = radius;
    }
    
    public boolean fits(Peg peg) {
        return this.radius >= peg.getRadius();
    }
}

// ==========================================
// Adapter
// ==========================================

// Adapter: Makes SquarePeg compatible with RoundHole
class SquarePegAdapter implements Peg {
    private SquarePeg peg;
    
    public SquarePegAdapter(SquarePeg peg) {
        this.peg = peg;
    }
    
    @Override
    public double getRadius() {
        // Convert square peg width to equivalent radius
        return (peg.getWidth() * Math.sqrt(2)) / 2;
    }
}

// ==========================================
// Main
// ==========================================

// Main class to test the Adapter Pattern
public class AdapterPatternExample {
    public static void main(String[] args) {
        // Create a round hole with radius 5
        RoundHole hole = new RoundHole(5);
        
        // Create a round peg of radius 5
        RoundPeg roundPeg = new RoundPeg(5);
        System.out.println("Round peg fits: " + hole.fits(roundPeg)); // true
        
        // Create square pegs
        SquarePeg smallSquarePeg = new SquarePeg(5);
        SquarePeg largeSquarePeg = new SquarePeg(10);
        
        // Can't use SquarePeg directly in RoundHole
        // hole.fits(smallSquarePeg); // This won't compile!
        
        // Use the adapter
        SquarePegAdapter smallAdapter = new SquarePegAdapter(smallSquarePeg);
        SquarePegAdapter largeAdapter = new SquarePegAdapter(largeSquarePeg);
        
        // Now the square pegs fit into the round hole
        System.out.println("Small square peg fits: " + hole.fits(smallAdapter)); // true
        System.out.println("Large square peg fits: " + hole.fits(largeAdapter)); // false
    }

    private final double price;

    public Product(String name, double price) {
        this.name = name;
        this.price = price;
    }

    public double getPrice() {

        return price;
    }

// ============================================================================
class Box implements Item {
    private final String name;
    private final List<Item> items = new ArrayList<>();

    public Box(String name) {
        this.name = name;
    }

    public void addItem(Item item) {
        items.add(item);
    }

    @Override
    public double getPrice() {
        System.out.println("📥 Opening box: " + name);
        double total = 0;
        
        for (Item item : items) {
            total += item.getPrice();
        }
        
        System.out.printf("📥 Total price of '%s': $%.2f%n", name, total);
        return total;
    }
}

Proxy:Proxy is a structural design pattern that lets you provide a substitute or placeholder for another 
object. A proxy controls access to the original object, allowing you to perform something 
either before or after the request gets through to the original object.

code template:



import java.util.*;

// ============================================================================
// 1. Interface (Target Interface)
// ============================================================================
interface ThirdPartyYouTubeLib {
    List<String> listVideos();
    String getVideoInfo(String id);
    void downloadVideo(String id);
}

// ============================================================================
// 2. Real Service (The Third-Party Library implementation)
// ============================================================================
class ThirdPartyYouTubeClass implements ThirdPartyYouTubeLib {
    @Override
    public List<String> listVideos() {
        simulateNetworkDelay("Fetching video list");
        return Arrays.asList("video1", "video2", "video3");
    }

    @Override
    public String getVideoInfo(String id) {
        simulateNetworkDelay("Getting info for " + id);
        return "Info about " + id;
    }

    @Override
    public void downloadVideo(String id) {
        simulateNetworkDelay("Downloading " + id);
        System.out.println("Downloaded video: " + id);
    }

    private void simulateNetworkDelay(String msg) {
        System.out.println(msg + " ... (slow)");
        try {
            Thread.sleep(1000); // Simulate network latency delay
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}

// ============================================================================
// 3. Proxy Class (Handles Caching Layers)
// ============================================================================
class CachedYouTubeClass implements ThirdPartyYouTubeLib {
    private ThirdPartyYouTubeLib realService;
    private List<String> listCache;
    private Map<String, String> videoInfoCache = new HashMap<>();
    private Set<String> downloadedVideos = new HashSet<>();
    private boolean needReset = false;

    public CachedYouTubeClass(ThirdPartyYouTubeLib service) {
        this.realService = service;
    }

    @Override
    public List<String> listVideos() {
        if (listCache == null || needReset) {
            System.out.println("[Proxy] Caching video list...");
            listCache = realService.listVideos();
        } else {
            System.out.println("[Proxy] Returning cached video list.");
        }
        return listCache;
    }

    @Override
    public String getVideoInfo(String id) {
        // If the video does not exist in cache or reset is forced
        if (!videoInfoCache.containsKey(id) || needReset) {
            System.out.println("[Proxy] Caching info for " + id);
            String info = realService.getVideoInfo(id);
            videoInfoCache.put(id, info);
        } else {
            // If it's cached before
            System.out.println("[Proxy] Returning cached info for " + id);
        }
        return videoInfoCache.get(id);
    }

    @Override
    public void downloadVideo(String id) {
        // First time downloading a video
        if (!downloadedVideos.contains(id) || needReset) {
            System.out.println("[Proxy] Downloading (and caching) " + id);
            realService.downloadVideo(id);
            downloadedVideos.add(id);
        } else {
            // Video is downloaded before
            System.out.println("[Proxy] Skipping download. Already downloaded: " + id);
        }
    }

    public void resetCache() {
        needReset = true;
        listCache = null;
        videoInfoCache.clear();
        downloadedVideos.clear();
        System.out.println("[Proxy] Cache has been reset.");
        needReset = false;
    }
}

// ============================================================================
// 4. Client Class (Uses the service via its interface)
// ============================================================================
class YouTubeManager {
    protected ThirdPartyYouTubeLib service;

    public YouTubeManager(ThirdPartyYouTubeLib service) {
        this.service = service;
    }

    public void renderVideoPage(String id) {
        String info = service.getVideoInfo(id);
        System.out.println("Rendering video page for: " + info);
    }

    public void renderListPanel() {
        List<String> videos = service.listVideos();
        System.out.println("Rendering video list: " + videos);
    }

    // Simulate User Action
    public void reactOnUserInput() {
        renderListPanel();
        renderVideoPage("video1");
        renderVideoPage("video1"); // Should use cache
        service.downloadVideo("video1");
        service.downloadVideo("video1"); // Should skip download
    }
}

// ============================================================================
// 5. Application (Configures and runs the system)
// ============================================================================
public class Application {
    public static void main(String[] args) {
        // Real service (3rd-party)
        ThirdPartyYouTubeLib realService = new ThirdPartyYouTubeClass();
        
        // Proxy that adds caching
        ThirdPartyYouTubeLib cachedService = new CachedYouTubeClass(realService);
        
        // Client uses the proxy instance instead of direct network class
        YouTubeManager manager = new YouTubeManager(cachedService);
        
        // First pass: Values are fetched via network and then cached
        manager.reactOnUserInput();
        
        System.out.println("\n--- Resetting Cache ---\n");
        ((CachedYouTubeClass) cachedService).resetCache();
        
        // Test again after cache reset (will query network once more)
        manager.reactOnUserInput();
    }
}

Chain of Responsibility lets you build a chain (or pipeline) of objects where each object (handler) can:
• Handle a request
• OR pass it along to the next handler in the chain
You avoid tightly coupled code and instead create flexible, extensible pipelines.

code templet :
// Step 1: Define the Handler interface / abstract base handler
abstract class ComplaintHandler {
    protected ComplaintHandler next;
    
    public ComplaintHandler(ComplaintHandler next) {
        this.next = next;
    }
    
    public abstract void handleComplaint(String complaint);
}

// Step 2: Concrete handler: Cashier
class Cashier extends ComplaintHandler {
    public Cashier(ComplaintHandler next) { 
        super(next); 
    }
    
    @Override
    public void handleComplaint(String complaint) {
        if (complaint.equals("price issue")) {
            System.out.println("Cashier: I can handle the price issue.");
        } else if (next != null) {
            System.out.println("Cashier: I can't handle this. Passing to Supervisor.");
            next.handleComplaint(complaint);
        } else {
            System.out.println("Cashier: No one can handle this.");
        }
    }
}

// Concrete handler: Supervisor
class Supervisor extends ComplaintHandler {
    public Supervisor(ComplaintHandler next) {
        super(next);
    }
    
    @Override
    public void handleComplaint(String complaint) {
        if (complaint.equals("damaged product") || complaint.equals("refund request")) {
            System.out.println("Supervisor: I can handle the " + complaint + ".");
        } else if (next != null) {
            System.out.println("Supervisor: I can't handle this. Passing to Manager.");
            next.handleComplaint(complaint);
        } else {
            System.out.println("Supervisor: No one can handle this.");
        }
    }
}

// Concrete handler: Manager
class Manager extends ComplaintHandler {
    public Manager(ComplaintHandler next) {
        super(next);
    }

    public void handleComplaint(String complaint) {

        }
    }

command: The Command Pattern is used to turn an action (like "copy", "paste", "save", etc.) into a separate object 
that holds all the details about that action.

code template:



import java.util.Stack;

// ============================================================================
// Step 1: Command Base Class
// ============================================================================
// Command interface / abstract base
abstract class Command {
    protected Application app;
    protected Editor editor;
    protected String backup;

    public Command(Application app, Editor editor) {
        this.app = app;
        this.editor = editor;
    }

    // Make a backup of the editor's state
    public void saveBackup() {
        backup = editor.getText();
    }

    // Restore the editor's state
    public void undo() {
        editor.setText(backup);
    }

    // Each command must implement execute() to carry out its operation
    // Returns true if the command changes the editor state (needs history tracking)
    public abstract boolean execute();
}

// ============================================================================
// Step 2: Concrete Commands
// ============================================================================
class CopyCommand extends Command {
    public CopyCommand(Application app, Editor editor) {
        super(app, editor);
    }

    @Override
    public boolean execute() {
        app.setClipboard(editor.getSelection());
        return false; // No state change to save for Copy command
    }
}

// Concrete command for Cut operation
class CutCommand extends Command {
    public CutCommand(Application app, Editor editor) {
        super(app, editor);
    }

    @Override
    public boolean execute() {
        saveBackup(); // Save the current state before cutting
        app.setClipboard(editor.getSelection());
        editor.deleteSelection();
        return true; // State has changed
    }
}

// Concrete command for Paste operation
class PasteCommand extends Command {
    public PasteCommand(Application app, Editor editor) {
        super(app, editor);
    }

    @Override
    public boolean execute() {
        saveBackup(); // Save the current state before pasting
        editor.replaceSelection(app.getClipboard());
        return true; // State has changed
    }
}

// Concrete command for Undo operation
class UndoCommand extends Command {
    public UndoCommand(Application app, Editor editor) {
        super(app, editor);
    }

    @Override
    public boolean execute() {
        app.undo();
        return false; // Undo doesn't change state directly, it reverts to previous state
    }
}

// ============================================================================
// Step 3: State Tracking & Receiver Classes
// ============================================================================
// CommandHistory class keeps track of the history of commands
class CommandHistory {
    private Stack<Command> history = new Stack<>();

    // Push a command onto the history stack
    public void push(Command command) {
        history.push(command);
    }

    // Pop the most recent command from the stack
    public Command pop() {
        if (!history.isEmpty()) {
            return history.pop();
        }
        return null;
    }
}

// Editor class simulates the text editor that changes text (Receiver)
class Editor {
    private String text;

    public String getText() {
        return text;
    }

    public void setText(String text) {
        this.text = text;
    }

    // Simulating selected text (simulated here as grabbing full text for simplicity)
    public String getSelection() {
        return text;
    }

    // Simulate deleting selected text
    public void deleteSelection() {
        text = "";
    }

    // Simulate replacing selected text with clipboard content
    public void replaceSelection(String clipboard) {
        this.text = clipboard;
    }
}

// ============================================================================
// Step 4: The Invoker Class
// ============================================================================
// Application class sets up the relationship between the commands and their invocations
class Application {
    private String clipboard;
    private Editor activeEditor;
    private CommandHistory history;

    public Application() {
        history = new CommandHistory();
    }

    // Set up the clipboard
    public void setClipboard(String clipboard) {
        this.clipboard = clipboard;
    }

    public String getClipboard() {
        return clipboard;
    }

    public void setActiveEditor(Editor editor) {
        this.activeEditor = editor;
    }

    // Execute a command and possibly add it to history
    public void executeCommand(Command command) {
        if (command.execute()) {
            history.push(command);
        }
    }

    // Perform an undo operation by popping the last command and executing its undo
    public void undo() {
        Command command = history.pop();
        if (command != null) {
            command.undo();
        }
    }
}

// ============================================================================
// Step 5: Demo / Main Program
// ============================================================================
// Main class to demonstrate the Command Pattern in action
public class CommandPatternDemo {
    public static void main(String[] args) {
        // Create the editor and set initial text
        Editor editor = new Editor();
        editor.setText("Hello, world!");

        // Create the application and set the active editor
        Application app = new Application();
        app.setActiveEditor(editor);

        // Show the initial state of the editor
        System.out.println("Initial text: " + editor.getText());

        // Simulate some operations: Copy, Cut, Paste, Undo
        
        // Copy operation (no change in text)
        app.executeCommand(new CopyCommand(app, editor));
        System.out.println("After Copy: " + editor.getText());

        // Cut operation (removes the selection from the text)
        app.executeCommand(new CutCommand(app, editor));
        System.out.println("After Cut: " + editor.getText());

        // Paste operation (replaces selection with clipboard content)
        app.executeCommand(new PasteCommand(app, editor));
        System.out.println("After Paste: " + editor.getText());

        // Undo operation (restores the text to the previous state)
        app.undo();
        System.out.println("After Undo: " + editor.getText());

        // Another operation to demonstrate Undo after multiple actions
        // Paste operation again (replaces selection again)
        app.executeCommand(new PasteCommand(app, editor));
        System.out.println("After second Paste: " + editor.getText());

        // Undo operation (restores the text to the previous state)
        app.undo();
        System.out.println("After second Undo: " + editor.getText());
    }

}

// ============================================================================
// 3- Context – The checkout system uses any payment method
// ============================================================================
class Checkout {
    private PaymentStrategy paymentStrategy;

    public void setPaymentStrategy(PaymentStrategy strategy) {
        this.paymentStrategy = strategy;
    }

    public void processOrder(double amount) {
        if (paymentStrategy == null) {
            throw new IllegalStateException("No payment strategy selected.");
        }
        paymentStrategy.pay(amount);
    }
}

// ============================================================================
// 4- Client Code – User selects how to pay at runtime
// ============================================================================
public class ECommerceApp {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Checkout checkout = new Checkout();

        System.out.print("Enter order amount: ");
        double amount = scanner.nextDouble();

        System.out.print("Choose payment method (card, paypal, crypto): ");
        String method = scanner.next();

        switch (method.toLowerCase()) {
            case "card":
                checkout.setPaymentStrategy(new CreditCardPayment("1234-5678", "123", "12/25"));
                break;
            case "paypal":
                checkout.setPaymentStrategy(new PayPalPayment("user@example.com", "password123"));
                break;
            case "crypto":
                checkout.setPaymentStrategy(new CryptoPayment("0xABC123XYZ"));
                break;
            default:
                System.out.println("Invalid payment method.");
                return;
        }

        checkout.processOrder(amount);
        scanner.close();
    }
}

Template:Template Method is a behavioral design pattern that lays out the blueprint of an algorithm in a base class — 
defining its structure step-by-step — while allowing subclasses to customize individual steps without 
touching the overall process.

cdoe template:






package application;

// ============================================================================
// 1- Abstract Class: Defines the algorithm template
// ============================================================================
abstract class Beverage {
    
    // Template Method (final so subclasses cannot change the order of execution)
    public final void prepareRecipe() {
        boilWater();
        brew();           // abstract step
        pourInCup();
        addCondiments();  // abstract step
    }

    // Common steps (same implementation for all beverages)
    private void boilWater() {
        System.out.println("Boiling water...");
    }

    private void pourInCup() {
        System.out.println("Pouring into cup...");
    }

    // Steps that subclasses MUST implement individually
    protected abstract void brew();
    protected abstract void addCondiments();
}

// ============================================================================
// 2- Concrete Classes: Implement specific steps of the template
// ============================================================================
// Concrete class for Coffee
class Coffee extends Beverage {
    @Override
    protected void brew() {
        System.out.println("Brewing coffee with filter...");
    }

    @Override
    protected void addCondiments() {
        System.out.println("Adding sugar and milk...");
    }
}

// Concrete class for Tea
class Tea extends Beverage {
    @Override
    protected void brew() {
        System.out.println("Steeping tea leaves...");
    }

    @Override
    protected void addCondiments() {
        System.out.println("Adding lemon...");
    }
}

// ============================================================================
// 3- Client Code: Executes the template method
// ============================================================================
public class TemplateMethodDemo {
    public static void main(String[] args) {
        
        System.out.println("Making Coffee:");
        Beverage coffee = new Coffee();
        coffee.prepareRecipe();
        
        System.out.println("\n-----------------------------\n");
        
        System.out.println("Making Tea:");
        Beverage tea = new Tea();
        tea.prepareRecipe();
    }
}
